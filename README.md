# Сервис для электронной торговли, ядро для интернет-магазина (в разработке)
## Модули product, category, utils, smartphone, lawngrass
### В модулях product и category созданы классы Product и Category.
Для класса Product определены свойства название (name), описание (description), цена (price), количество в наличии (quantity). Родительский для класса продуктов - 
абстрактный класс BaseProduct. В абстрактном классе описана общая функциональность, которая должна быть у каждого продукта.
Для класса Category определены свойства название (name), описание (description), список товаров категории (products). 
Для этих двух классов добавлена инициализация, чтобы каждый параметр был передан при создании объекта и сохранен. 
Также для класса Category добавлены два атрибута класса. Доступ к этим атрибутам есть у каждого объекта класса, в них хранится общая информация для всех объектов. 
Атрибуты хранят в себе количество категорий и количество товаров.
Для класса Product добавлено строковое отображение следующего типа: "Название продукта, 80 руб. Остаток: 15 шт."
Для удобства работы с продуктами реализована возможность их складывать (в итоге получается полная стоимость всех товаров на складе).
Для класса Category добавлено строковое отображение следующего типа: "Название категории, количество продуктов: 200 шт."
В модуле utils реализована подгрузка данных по категориями и товарам из файла JSON.
В модуле category_iterator создан вспомогательный класс, с помощью которого можно перебирать товары одной категории. 
Класс принимает на вход объект класса категории и производит итерацию по товарам, которые хранятся в данной категории.
То есть метод выполнения следующего шага итерации должен возвращать очередной товар категории.
Реализован класс-миксин, который при создании объекта (при работе метода __init__) печатает в консоль информацию о классе и параметрах созданного объекта.

### В модулях smartphone и lawngrass созданы одноименные классы.
Классы Smartphone и LawnGrass являются классами-наследниками от исходного класса Product. Функциональность сложения объектов 
предусматривает возможность складывать товары только из одинаковых классов продуктов, т.е. нельзя сложить смартфон и траву газонную, 
в таком случае выйдет ошибка TypeError. Метод добавления объектов продуктов в категории защищен: кроме смартфонов, травы газонной или других 
продуктов в список нельзя добавить ничего другого. Метод добавления продукта в категорию предусматривает добавление только класса Product 
или наследников этого класса.

## Режимы доступа.
Атрибут списка товаров класса Category (products) имеет приватный режим доступа. 
Реализован метод add_product() для добавления продукта в этот атрибут. Для приватного атрибута products реализован геттер, 
возвращающий строку со всеми продуктами в приватном атрибуте products. Каждый продукт в геттере сформирован как строка строго по шаблону: 
"Название продукта, X руб. Остаток: X шт.\n".
Атрибут price класса Product имеет приватный режим доступа. Реализован геттер для этого атрибута, возвращающий значение приватного атрибута цены. 
Также для атрибута price реализован сеттер, принимающий два аргумента — self и новое значение цены. В сеттере реализована проверка 
на положительное значение новой цены (если положительное, то значение цены в атрибуте обновляется). Если новое значение цены не положительное, 
то новое значение приватному атрибуту не присваивается, в консоль выводится сообщение «Цена не должна быть нулевая или отрицательная». 
Также осуществляется сравнение старого и нового значений атрибута price: если новое значение ниже предыдущего, то оно может быть присвоено атрибуту 
в случае согласия пользователя.


## Тестирование.
Написаны тесты для классов, которые проверяют корректность инициализации объектов класса Category, Product, Smartphone и LawnGrass, работу миксина,
подсчет количества продуктов, подсчет количества категорий.
